# Журнал змін

Формат за [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/), версії — [SemVer](https://semver.org/lang/uk/).

## [Unreleased]

> Готується до релізу як 0.3.0. Дата проставляється в день тега.

### Додано
- **Автооновлення** через `electron-updater` + GitHub Releases. Folio фоном тягне новий реліз і пропонує перезапуск; якщо проігнорувати — оновиться при наступному закритті. Windows та Linux (macOS — вручну, бо збірка без підпису).
- **Вибір моделі Claude** per-компанія у налаштуваннях. Діє і на чат, і на фонові задачі. Список моделей не захардкоджений — Folio питає встановлений Claude Code, які моделі доступні на тарифі користувача, і показує їх з описами (Opus 1M, Fable, Sonnet, Haiku…). Нові моделі з'являються самі, без оновлення Folio; якщо CLI не відповідає — фолбек на аліаси opus/sonnet/haiku.
- **Черга підтверджень** — кілька паралельних мутацій більше не перетирають одна одну; бар показує першу + лічильник «+N у черзі».
- Версія застосунку в sidebar тепер читається з білда (правильна після автооновлення).

### Покращено
- **Circuit breaker** для інтеграцій / автозадач / авто-імпортів: після серії невдач інтервал зростає експоненційно (до 32×), перший успіх скидає лічильник.
- **Timeout 30 хв** на будь-який фоновий запуск — зависання Claude більше не блокує слот назавжди.
- **Timeout 10 хв** на непідтверджену дію — чат не зависає, якщо UI впав посеред підтвердження.
- Тости розрізняють «Автозадача» та «Авто-імпорт»; скасування авто-імпорту тепер дійсно його зупиняє.
- Інтеграції фіксують статус помилки — у налаштуваннях видно червоний індикатор і бейдж.
- Індикатор «обробляю файли…» поки парсяться вкладення.

### Виправлено
- Падіння рендера markdown більше не кладе весь чат — повідомлення деградує до plain-тексту (error boundary).
- Wizard авто-імпорту: опція «імпортувати останній файл» тепер запускає імпорт одразу, а не чекає наступного тіка.
- **Аналіз Google Sheets — неправильні підрахунки.** Тул `gdrive_get_file_content` тепер приймає `gid` і читає конкретну вкладку (раніше CSV-експорт мовчки повертав лише першу), віддає CSV-текст із row/char count для звірки повноти, і CSV із правильним екрануванням (значення з `|`, комами, переносами більше не ламають парсинг). Без `gid` — явне попередження, що зчитано тільки першу вкладку.
- **Поведінка при аналізі зовнішніх даних.** Системний промпт тепер вимагає pre-flight перевірку перед будь-яким підрахунком: правильна вкладка (gid), повнота читання (row/char count), звірка з ground-truth юзера. При розбіжності — СТОП і чесне «не зміг прочитати повністю» замість «приблизних» чи правдоподібних, але хибних чисел.

## [0.2.0] — 2026-05-18

Перший публічний реліз.

### Додано
- **MCP-сервери** — підключення зовнішніх інструментів per-компанія, з майстром налаштування і скілом `mcp-setup`.
- Бандл Node/uv-бінарників у застосунку, щоб MCP-сервери запускались без окремого встановлення рантаймів.
- **Google Drive** — клієнт на API-ключі + майстер імпорту з папки та прив'язки файлів, які підтягуються за розкладом.
