# Журнал змін

Формат за [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/), версії — [SemVer](https://semver.org/lang/uk/).

## [1.0.0] — 2026-09-30

### Додано
- **Мультиагентність.** Claude розкладає запит на незалежні частини і запускає субагентів паралельно: `finmap-analyst` (один зріз даних — період, рахунок, проєкт), `statement-reconciler` (одна виписка проти одного рахунку), `web-researcher` (API-доки, MCP-пакети, податкові правила). Усі три — тільки читання; будь-які зміни в Finmap робить головний агент, тож підтвердження йдуть по черзі, як раніше. У чаті під відповіддю — живі картки агентів: тип, задача, поточний тул, кількість викликів, час. Після відповіді на hover видно «✦ агентів: N» з деталями.
- **Ліміти підписки Claude** в хедері чату: `⏱ 38%` — використання 5-годинного вікна, у тултіпі час оновлення («о 14:00 — через 2 год 10 хв») і тижневий ліміт. Жовтий від 70%, червоний від 90% і коли ліміт вичерпано.
- **Голосове введення** — кнопка мікрофона в полі вводу: натиснув, надиктував, натиснув ще раз — текст з'явився в полі, відправляєш після перегляду; `Esc` скасовує. Розпізнає Groq Whisper (`whisper-large-v3-turbo`) з ключем, вшитим у збірку: користувачу нічого налаштовувати, в налаштуваннях лише мова розпізнавання. Записи без голосу не відправляються (рівнемір на мікрофоні), а типові галюцинації Whisper на тиші («Дякую за перегляд») відкидаються.
- **Глобальні налаштування** (`Налаштування` в sidebar): мова інтерфейсу, мова відповідей асистента, мова розпізнавання голосу.
- **Мова інтерфейсу: українська / англійська.** Весь UI на словниках (`src/renderer/i18n/strings/*.ts`, 436 ключів); `npm run check:i18n` ловить пропущені ключі й кирилицю поза словниками.
- **Мова відповідей асистента**: авто / українська / англійська — окреме правило в системному промпті, діє на всі компанії та фонові задачі.
- **Стрімінг по токенах.** Відповідь з'являється по мірі генерації. Автоскрол тримається низу лише поки ти сам унизу.
- **Індикатор контексту** в хедері: кільце із заповненням контекстного вікна Claude, у тултіпі — токени.
- **Час відповіді** на hover під повідомленням, у тултіпі — токени, ходи, модель. Вартість у доларах не показується: на підписці мають значення лише ліміти.
- **Позначка «історію стиснуто»**, коли Claude Code робить автокомпакт контексту.
- **Drag-and-drop** файлів у чат і **вставка з буфера** (Ctrl+V скріншота чека або файлів з Провідника).

- **Ліміти Finmap API враховано.** Усі виклики до Finmap ідуть через спільний для компанії лімітер (10 запитів / 5 с, 120 / хв): запити стають у чергу замість того, щоб отримувати 429; лімітер синхронізується із заголовками `Used-Req-Count` / `Next-Possibility-At`, тож враховує й інші інтеграції та AI-конектори тієї ж компанії. Якщо 429 усе ж прийшов — чекаємо `Retry-After` і повторюємо (це безпечно і для створення: відхилені запити Finmap не обробляє). Фонові задачі займають не більше 70% вікна, щоб чат не чекав за автоімпортом. `http_request` до `api.finmap.online` іде через ту саму чергу.
- **Оновлення й видалення за `externalId`** для операцій та інвойсів (`patch_operation`, `delete_operation`, `update_invoice`, `delete_invoice`) — синку не треба спершу шукати операцію, мінус один запит на кожну.
- **PDF інвойсу**: тул `download_invoice_pdf` зберігає рендер у `Завантаження/Folio` і відкриває папку.
- Інвойси: товар можна вказати назвою (`label`, Finmap знайде або створить), додано `shippingVat` і `confirmedInvoice` при створенні. `get_operations`: фільтр `useDateOfPayment`. `patch_operation`: `externalDevComment`.

### Змінено
- **Claude Agent SDK.** Застарілий `@anthropic-ai/claude-code` 1.0.128 замінено на `@anthropic-ai/claude-agent-sdk` 0.3 (пара до Claude Code 2.1), zod 3 → 4. Тули Finmap для чату віддаються через локальний MCP-ендпоінт на `127.0.0.1` з окремим токеном на кожен запуск — інакше субагенти їх не бачать.
- **Ізоляція від особистого Claude Code.** Сесії Folio більше не підтягують глобальні налаштування, хуки, плагіни і claude.ai-конектори користувача — лише те, що передає сам Folio.
- Фонові задачі більше не продовжують розмову чату: промпти автозадач не потрапляють в історію, і їхній session id не перезаписує чатовий.
- Інсталятор не тягне бандлений бінарник Claude Code з SDK (~240 МБ): Folio працює з уже встановленим CLI.

### Безпека
- Мутації MCP-серверів, прив'язок папок, автозадач і `toggle_integration` більше не підтверджуються автоматично — раніше вони стояли в списку auto-approve, і prompt injection у файлі з Drive чи веб-сторінці міг, наприклад, додати MCP-сервер з довільною командою.
- Вимкнено вбудовані тули, що виконують команди чи пишуть файли (Bash, PowerShell, Write, Edit…); невідомі вбудовані тули за замовчуванням заборонені.
- `http_request` без підтвердження — тільки GET/HEAD; POST/PUT/DELETE йдуть через підтвердження.
- Встановлений Folio більше не пробує `localhost:5173`: будь-який сторонній Vite-проєкт на цьому порту отримав би доступ до API Folio.
- Відносне посилання у відповіді Claude більше не підміняє вікно застосунку.
- Тули невідомих MCP-джерел підтверджуються, а не пропускаються.

### Виправлено
- **Паралельні запуски в одній компанії** (чат + автозадача + синк) більше не заважають одне одному: кожен має власний MCP-сервер і AbortController. Раніше кнопка «Стоп» могла зупинити фонову задачу замість чату, а результат тула — піти не в той процес і повісити запуск.
- **Сховище пишеться атомарно** (tmp + rename). Пошкоджений файл при старті зберігається як `.corrupt-<час>`, а не мовчки перезаписується порожнім — раніше збій живлення під час запису стирав усі компанії й історію.
- **Лише один екземпляр Folio**: другий запуск фокусує перше вікно, а не стартує другий планувальник (задачі виконувались двічі → дублікати операцій).
- Налаштування компанії, відкриті перед переходом через Ctrl+K в іншу, більше не зберігаються в чужу компанію.
- Enter у будь-якому полі налаштувань компанії більше не закриває модалку з втратою введеного ключа.
- Новий Finmap-ключ діє одразу, без перезапуску; візард імпорту бачить щойно збережений ключ.
- Візард імпорту з Google Drive знову модальний (оверлей, не рендериться всередині форми).
- Скасована автозадача або прострочений логін більше не записуються як «успішно» з порожнім результатом; `isAuthError` більше не плутає 403 від Drive з виходом із Claude.
- Finmap API: при таймауті повторюються лише запити на читання — створення операцій більше не дублюються.
- Google Drive: таймаути 60 с і ліміт 15 МБ на файл (раніше відео в папці могло покласти main-процес).
- Пошук сплітів у звірці обмежено — великі виписки більше не заморожують застосунок на хвилини.
- Windows: `claude.cmd`/npm-шими більше не ламають запуск SDK — використовується `.exe` або `cli.js`.
- CI: інсталятори з GitHub тепер справді містять вбудовані uv і Node.js — workflow не запускав `fetch-binaries`, тож вони збирались без рантаймів. Збірка тега без секрету `GROQ_API_KEY` падає з явною помилкою, а не випускає реліз без голосу.
- Вкладення, видалене до відправки, дає помилку в чаті, а не вічний спінер.
- Видалення компанії прибирає її MCP-сервери (з токенами) і прив'язки папок.
- MCP-сервер з кириличною назвою, назвою `finmap` чи дублем тепер показує помилку, а не мовчки не зберігається / не перекриває вбудований.
- Пошук: пізня відповідь на старий запит не перетирає нові результати.
- Графік з некоректним JSON показує помилку графіка, а не ламає все повідомлення.
- Подвійний клік «Створити» більше не створює дві компанії; рядки прив'язок оновлюються після запуску; тули MCP-серверів з `_` у назві підписуються коректно.
- macOS: `NSMicrophoneUsageDescription` в Info.plist.
- Пошук по чатах не показує службові маркери Folio.

## [0.3.0] — 2026-09-01

### Додано
- **Автооновлення** через `electron-updater` + GitHub Releases. Folio фоном тягне новий реліз і пропонує перезапуск; якщо проігнорувати — оновиться при наступному закритті. Windows та Linux (macOS — вручну, бо збірка без підпису).
- **Вибір моделі Claude** per-компанія у налаштуваннях. Діє і на чат, і на фонові задачі. Список моделей не захардкоджений — Folio питає встановлений Claude Code, які моделі доступні на тарифі користувача, і показує їх з описами (Opus 1M, Fable, Sonnet, Haiku…). Нові моделі з'являються самі, без оновлення Folio; якщо CLI не відповідає — фолбек на аліаси opus/sonnet/haiku.
- **Черга підтверджень** — кілька паралельних мутацій більше не перетирають одна одну; бар показує першу + лічильник «+N у черзі».
- Версія застосунку в sidebar тепер читається з білда (правильна після автооновлення).

### Покращено
- **Circuit breaker** для інтеграцій / автозадач / авто-імпортів: після серії невдач інтервал зростає експоненційно (до 32×), перший успіх скидає лічильник.
- **Timeout 30 хв** на будь-який фоновий запуск — зависання Claude більше не блокує слот назавжди.
- **Timeout 10 хв** на непідтверджену дію — чат не зависає, якщо UI впав посеред підтвердження.
- Тости розрізняють «Автозадача» та «Авто-імпорт»; скасування авто-імпорту тепер дійсно його зупиняє.
- Інтеграції фіксують статус помилки — у налаштуваннях видно червоний індикатор і бейдж.
- Індикатор «обробляю файли…» поки парсяться вкладення.

### Виправлено
- Падіння рендера markdown більше не кладе весь чат — повідомлення деградує до plain-тексту (error boundary).
- Wizard авто-імпорту: опція «імпортувати останній файл» тепер запускає імпорт одразу, а не чекає наступного тіка.
- **Аналіз Google Sheets — неправильні підрахунки.** Тул `gdrive_get_file_content` тепер приймає `gid` і читає конкретну вкладку (раніше CSV-експорт мовчки повертав лише першу), віддає CSV-текст із row/char count для звірки повноти, і CSV із правильним екрануванням (значення з `|`, комами, переносами більше не ламають парсинг). Без `gid` — явне попередження, що зчитано тільки першу вкладку.
- **Поведінка при аналізі зовнішніх даних.** Системний промпт тепер вимагає pre-flight перевірку перед будь-яким підрахунком: правильна вкладка (gid), повнота читання (row/char count), звірка з ground-truth юзера. При розбіжності — СТОП і чесне «не зміг прочитати повністю» замість «приблизних» чи правдоподібних, але хибних чисел.

## [0.2.0] — 2026-05-18

Перший публічний реліз.

### Додано
- **MCP-сервери** — підключення зовнішніх інструментів per-компанія, з майстром налаштування і скілом `mcp-setup`.
- Бандл Node/uv-бінарників у застосунку, щоб MCP-сервери запускались без окремого встановлення рантаймів.
- **Google Drive** — клієнт на API-ключі + майстер імпорту з папки та прив'язки файлів, які підтягуються за розкладом.

## [0.1.0] — [0.1.8] — 2026-04-29 … 2026-05-07

Ранні пре-релізи, публічно не анонсовані. У цьому циклі склалась база застосунку:
чат із Claude Code, Finmap MCP-тули, набір скілів (звірка виписки, прогноз кешфлоу,
чек із фото, квартальний податковий звіт тощо), інтеграції та планувальник фонових задач.

Основні виправлення:

- `0.1.8` — вхід у Claude Code.
- `0.1.7` / `0.1.5` / `0.1.1` — шляхи, інсталятор, збірка.
- `0.1.6` — бандл скілів у застосунок.
- `0.1.4` — запуск термінала на Windows + визначення авторизації.
- `0.1.2` — парсинг PDF.
