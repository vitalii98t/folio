# Charts Output (Графіки в чаті)

## Як це рендериться
Folio розпізнає у твоїй відповіді fenced-код-блок з мовою `finapse-chart` і JSON-вмістом. Замість сирого JSON юзер бачить інтерактивний графік (бібліотека recharts).

## Шаблон

````
```finapse-chart
{"type":"bar","title":"Витрати за тиждень","xKey":"day","series":[{"key":"expense","label":"Витрати"}],"data":[{"day":"Пн","expense":1200},{"day":"Вт","expense":800}]}
```
````

JSON має бути в одному рядку (без переносів усередині) — іначе парсер може не справитися з деякими рендерами.

## Три типи графіків — коли який

### 1. `bar` — категорійні порівняння
Коли вісь X — категорії (рахунки, контрагенти, дні тижня, проекти):
- "витрати по категоріях за квітень"
- "топ-10 контрагентів по обороту"
- "доходи vs витрати по місяцях"

```json
{"type":"bar","title":"Витрати по категоріях","xKey":"category","series":[{"key":"amount","label":"Сума"}],"data":[{"category":"Оренда","amount":15000},{"category":"Зарплати","amount":80000},{"category":"Реклама","amount":12000}]}
```

### 2. `line` — часові ряди
Коли вісь X — час, треба показати ДИНАМІКУ:
- "динаміка балансу за місяць"
- "щоденні витрати"
- "виторг по тижнях"

```json
{"type":"line","title":"Динаміка балансу","xKey":"date","series":[{"key":"balance","label":"Баланс, грн"}],"data":[{"date":"01.04","balance":50000},{"date":"08.04","balance":48000},{"date":"15.04","balance":42000}]}
```

### 3. `pie` — пропорційний розподіл
Коли треба показати ЧАСТКИ цілого:
- "розподіл витрат по категоріях"
- "структура доходів"
- "по яких контрагентах основна частина обороту"

```json
{"type":"pie","title":"Структура витрат за квітень","data":[{"name":"Оренда","value":15000},{"name":"Зарплати","value":80000},{"name":"Реклама","value":12000}]}
```

**Pie не має `xKey` і `series`** — тільки `data` зі схемою `{name, value}`.

## Жорсткі правила

### Правило 1: один графік на одну відповідь
Не дублюй чарт у кількох форматах ("ось і таблиця, і ще графік"). Або графік, або таблиця. Графік — пріоритет, якщо це доречно за визначенням вище.

### Правило 2: ≥3 точок даних
Для 1-2 значень просто скажи числа: *"Витрати в квітні — 12 500 грн, у травні — 18 200 грн"*. Графік на 2 точки виглядає дурнувато.

### Правило 3: takeaway-речення поряд
Графік без коментаря — погано. Перед або після додай 1-2 речення інтерпретації:

> *"Витрати зросли у середу — основна стаття: оренда офісу."*
>
> ```finapse-chart
> {...}
> ```

### Правило 4: значення — числа без валюти
У `data` пиши `1200`, не `"1200 ₴"`. Інакше Recharts не зможе побудувати осі.
Валюту вказуй у `label` серії: `{"key":"amount","label":"Сума, грн"}`.

### Правило 5: підписи коротко і українською
- Категорії довші за 15 символів — скорочуй ("Командоутворення" → "Команд.").
- Дати — у форматі `01.04` чи `Пн`/`Вт`, не повний ISO.
- `title` — короткий і суть: "Витрати по категоріях", не "Аналіз витратних операцій по структурі категорій".

## Кольори (опційно)
За замовчуванням Folio розфарбовує сам із палітри з 8 кольорів. Якщо хочеш зафіксувати — додай `color` у series:
```json
{"series":[{"key":"income","label":"Доходи","color":"#10b981"},{"key":"expense","label":"Витрати","color":"#ef4444"}]}
```

Використовуй явні кольори тільки якщо є семантика (зелений = доходи, червоний = витрати, синій = баланс). Інакше залиш дефолти.

## Антипатерни

❌ **Графік для 1-2 значень** — пуста плашка, виглядає глюкаво.

❌ **Графік без takeaway** — юзер не зрозуміє що ти хотів сказати.

❌ **Дві серії з різними одиницями** на одній осі ("кількість" і "сума") — графік стає нечитабельним. Або зроби два окремих, або тільки одну з двох.

❌ **Pie на 10+ елементів** — ніхто не розрізнить шматочки. Згрупуй у "Інше" все, що менше 3% від загальної суми.

❌ **Currency strings у `value`/`data`** — `"1 200 ₴"` не парситься.
