# Folder Import Setup (Авто-імпорт з папки Google Drive)

## Що ти робиш
Цей флоу налаштовується через **нативний UI-wizard** Folio, не через діалог у чаті. Твоя задача — пояснити юзеру **де знайти кнопку** і **які кроки на нього чекають**, а не намагатись провести через все самостійно у чаті.

Чому через UI: підключення Google Drive потребує API-ключа і URL-папки, перевірки доступу до Drive API, валідації. У UI це робиться за хвилину з кнопками і полями. В чаті — болісно (Claude не може відкривати браузер, не може ввести ключ у Google Cloud Console замість юзера).

## Що казати юзеру

Коли він каже "хочу автоімпорт з гугл-папки" — дай йому **коротку інструкцію де налаштувати**, без зайвих діалогів. Текст приблизно такий:

```
Для цього є нативний wizard у Folio — налаштовується за хвилину:

1. Натисни шестерню сесії (⚙️ Settings) → секція **"Авто-імпорт з папок"** → кнопку **+**
2. Wizard проведе через 6 кроків:
   • Google Drive API key (один раз — створюється у Google Cloud Console, 5 хв)
   • URL папки Google Drive (треба зробити її shared "Anyone with the link")
   • Який рахунок Finmap використовувати
   • Контекст обробки (як визначати категорію/контрагента/тип з файлів)
   • Інтервал перевірки (15 хв / 30 хв / 1 год / 6 год / 1 день)
   • Що робити з останнім файлом у папці (пропустити чи імпортувати)
3. Після setup'у Folio сам перевірятиме папку і авто-імпортуватиме нові файли.

Якщо вже ВСЕ налаштував і хочеш щось зробити з імпортами (запустити вручну, змінити контекст, видалити) — у тій же секції Settings є кнопки ▶ (запустити зараз), ✏️ (редагувати), 🗑 (видалити).
```

## Як отримати Google Drive API key (для довідки юзеру)

Якщо юзер запитає **"а як отримати API key"** — поясни покроково:

1. https://console.cloud.google.com → створи новий проект (або обери існуючий)
2. APIs & Services → Library → знайди "Google Drive API" → Enable
3. APIs & Services → Credentials → Create credentials → API key
4. (Опційно для безпеки) Restrict key → API restrictions → тільки Google Drive API
5. Копіюй ключ — встав у Folio wizard'і у Кроці 1

Це **разова процедура на ~5 хвилин**. Ключ зберігається локально в Folio, прив'язаний до поточної сесії.

## Як налаштувати папку як публічну (для довідки)

Якщо юзер запитає **"а як зробити папку доступною"**:

1. Зайди в Google Drive (web)
2. Правою кнопкою на потрібну папку → **Share**
3. У "General access" обери **"Anyone with the link"** → роль: **Viewer**
4. Натисни "Copy link" → встав у Folio wizard'і у Кроці 2

URL папки виглядає як `https://drive.google.com/drive/folders/1AbCdEf...`. Folio парсить folder ID автоматично з нього.

## Безпекова дискусія (якщо юзер хвилюється)

- **"Anyone with the link"** не означає публічно у пошуковиках. URL містить 33-символьний випадковий ID — практично неможливо вгадати. Та сама модель що для Google Docs share links.
- Folio бачить **тільки ту папку**, яку юзер явно поділив. Не доступ до всього Drive.
- API key зберігається локально на машині юзера, ніколи не шлеться в Anthropic чи кудись ще — він використовується лише для Drive API запитів самим Folio.

## Антипатерни

❌ **Не намагайся** провести юзера через 6 кроків діалогом у чаті — це дублює UI-wizard і занадто болісно.
❌ **Не питай** у юзера "дай мені API ключ" — це робота wizard'у, який зашифрує і збереже. Якщо юзер кине ключ у чат — попроси видалити повідомлення і не записуй його ніде.
❌ **Не намагайся викликати** `mcp__finmap__create_file_binding` напряму — UI-wizard зробить це через IPC з правильно зібраним baseline.
❌ **Не вгадуй folderId з URL** у чаті — wizard парсить його сам.

## Якщо юзер ВЖЕ налаштував binding і хоче щось з ним зробити

- "запусти зараз" / "перевір прямо зараз" — direct CLI fallback не потрібен, нехай натисне ▶ у Settings
- "зміни контекст" / "поміняй промт" — у Settings є кнопка ✏️ для редагування
- "вимкни тимчасово" — у Settings є toggle ⚪
- "видали" — кнопка 🗑

Або ти можеш викликати `mcp__finmap__list_file_bindings` щоб подивитись що налаштовано, і `mcp__finmap__update_file_binding` щоб змінити контекст/інтервал через chat. Видаляти через chat не рекомендую — це необоротна дія, краще через UI з підтвердженням.
